Real-Time Monocular Bird's-Eye View (BEV) Navigation

Built an end-to-end perception pipeline that transforms live monocular camera streams from a mobile robot into a real-time semantic Bird's-Eye-View (BEV) map for indoor navigation. The system combines monocular depth estimation, semantic segmentation, 3D geometric projection, and semantic occupancy mapping to generate an environment-aware top-down representation that supports autonomous navigation and obstacle avoidance without requiring LiDAR or RGB-D sensors.

REF#002 // SPATIAL_MEMORY COMPLETE

Stateful ROS 2 Perception System

A decoupled ROS 2 architecture that upgrades standard object detection into a persistent, queryable spatial memory system. Built with Python and YOLOv8, this pipeline uses ByteTrack to track unique object instances across frames and stores their spatial coordinates in an auto-pruning SQLite database. Operators can interact with the robot's memory via a custom terminal CLI to ask questions like, "Where did you last see the bottle?"

GitHub Intelligence Agent

REF#004 // PATENT COMPLETE

Proximity-Activated Audio Product Labels

This patent-pending accessibility system provides visually impaired users with hands-free audio announcements about retail products, completely eliminating the need for smartphone apps or physical barcode scanning. By leveraging Wi-Fi beacon proximity detection and RSSI threshold algorithms, the device accurately triggers real-time, synchronized audio and visual information when a user enters a 1–2 meter range. This creates a more independent, accessible, and seamless shopping experience without relying on traditional visual cues.

ESP32 & FreeRTOS Hardware Integration (I2C OLED, DAC, LM386) Wi-Fi Proximity Detection & RSSI Algorithms
REF#005 // SECURITY COMPLETE

Zero-Trust Encrypted File Sharing System

This Zero Trust file-sharing system ensures absolute data privacy by enforcing strict client-side hybrid encryption (AES-GCM and X25519) so the backend infrastructure acts merely as an untrusted registry. Utilizing a robust cryptographic identity pipeline with SHA-256 hashes and Ed25519 signatures, the system enables secure, multi-user sharing. It guarantees that the server never has access to plaintext data or private keys, providing true end-to-end security without reliance on backend trust.
